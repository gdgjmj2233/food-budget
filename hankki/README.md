# 한끼예산

주간/월간 식비 예산을 정하면 학교 주변 식당 중 예산에 맞는 곳을 추천하고,
먹은 걸 기록할 때마다 남은 예산을 남은 끼니로 다시 나눠 다음 한 끼 금액을 계산하는 앱.

- Expo SDK 58 · Expo Router · TypeScript
- 기록과 설정은 기기에 저장 (AsyncStorage)

## 실행

```bash
npm install
npx expo start          # QR이 뜨면 Expo Go로 찍기 (PC와 휴대폰 같은 Wi-Fi)
npx expo start --tunnel # 같은 Wi-Fi가 아니거나 연결이 안 될 때
npx expo start --web    # PC 브라우저로 보기
```

패키지는 `npm install` 대신 `npx expo install <패키지>`로 추가해야 SDK에 맞는 버전이 설치됩니다.

## 폴더 구조

```
src/
  app/                 화면 (파일 하나 = 화면 하나, Expo Router)
    _layout.tsx        하단 탭, 전역 Provider
    index.tsx          홈: 다음 한 끼 권장 금액, 추천 3곳
    recommend.tsx      추천: 카테고리/정렬/예산 안만 보기
    history.tsx        기록: 날짜별 먹은 기록, 되돌리기
    budget.tsx         예산: 기간·금액·끼니·주말 제외, 새 기간 시작
  lib/budget.ts        예산 계산 (순수 함수, UI와 분리)
  store/budget-store.tsx  설정·기록 상태와 기기 저장

  components/          공용 UI (카드, 버튼, 식당 항목, 토스트)
  theme.ts             색상
```

## 예산 계산 규칙 (`src/lib/budget.ts`)

- 기간: 주간은 시작일부터 7일, 월간은 다음 달 같은 날 전까지
- 남은 일수: 오늘부터 기간 끝까지 (주말 제외 옵션 반영)
- 남은 끼니: 남은 일수 × 하루 끼니 − 오늘 이미 먹은 끼니
- **다음 한 끼 권장 = 남은 예산 ÷ 남은 끼니** (100원 단위 내림)
- 하루 권장 = 남은 예산 ÷ 남은 일수
- 상태: 남은 예산이 마이너스면 "초과", 한 끼 권장이 처음 기준의 85% 미만이면 "주의"
- 계획한 끼니를 다 먹었는데 기간이 남았으면(예: 주말 제외인데 주말) 남은 예산 전체를 쓸 수 있는 금액으로 표시

## 식당 데이터 (`src/data/places.ts`)

- 인하대(용현캠퍼스) 정문·후문·인하대역 주변 식당 96곳, 메뉴 약 410개
- 출처: 다이닝코드 식당 정보, 2026년 10월 수집. 가격은 바뀔 수 있음
- 술집·카페·고깃집처럼 혼자 한 끼 먹기 어려운 곳은 제외
- 도보 시간은 정문·후문 중 가까운 쪽에서의 직선거리로 계산한 대략값
- 가격이 바뀌면 해당 식당의 `menus` 배열만 고치면 됨
