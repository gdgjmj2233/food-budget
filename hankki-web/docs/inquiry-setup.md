# 문의·제보 받기 (Google 스프레드시트)

앱에서 보낸 **제보와 문의가 우리 Google 계정의 스프레드시트에 저절로 한 줄씩 쌓여요.**
서버 없이 Google Apps Script(무료)를 쓰고, 스프레드시트는 Google Drive에서 엑셀처럼 보고 고칠 수 있어요. 언제든 엑셀 파일(.xlsx)로도 받을 수 있어요.

받는 코드는 [inquiry-apps-script.gs](inquiry-apps-script.gs) 한 파일이에요.

## 시트 구성

종류마다 시트(아래쪽 탭)가 따로 생겨요. 시트가 없으면 첫 글이 올 때 저절로 만들어져요.

| 시트 | 앱에서 보내는 곳 | 칸 |
| --- | --- | --- |
| `메뉴 정보 수정` | 식당 카드 오른쪽 위 **메뉴 정보 수정 제보** (메뉴가 없는 주변 음식점 카드 포함) | 접수 시각 · 내용 종류 · 식당 이름 · 주소 · 내용 · 보던 화면 · 기기 · 처리 상태 · 메모 |
| `식당 미등록 제보` | 주변 식당 화면, 지도/목록 버튼 왼쪽 **식당 미등록 제보** | 접수 시각 · 식당 이름 · 위치 · 보던 화면 · 기기 · 처리 상태 · 메모 |
| `문의` | 문의하기 (버그 신고·건의 등) | 접수 시각 · 종류 · 내용 · 연락처 · 보던 화면 · 기기 · 처리 상태 · 메모 |

- **내용 종류**: 가격이 달라요 / 없어진 메뉴 / 새 메뉴 / 기타 중 고른 것. 메뉴 정보가 없는 곳에서 보낸 제보는 `메뉴 없음`이고, 이름이 같은 지점을 구분할 수 있게 **주소**가 같이 들어가요.
- **처리 상태**: 새 글은 `접수`로 들어가요. 칸을 눌러 `확인 중` / `반영함` / `반영 안 함`을 고르며 정리해요.
- **메모**: 팀이 자유롭게 적는 칸이에요.

## 이미 연결해 둔 경우: 받는 코드만 바꾸기

앱의 `INQUIRY_URL`(`src/lib/inquiry.ts`)에 이미 주소가 들어 있으면 이 방법만 하면 돼요. **주소는 바뀌지 않아서 앱은 고칠 필요가 없어요.**

1. Google Drive에서 문의가 쌓이던 스프레드시트(예: `한끼예산 문의`)를 열어요.
2. 위쪽 메뉴 **확장 프로그램 → Apps Script**를 열어요.
3. 들어 있는 코드를 **모두 지우고** [inquiry-apps-script.gs](inquiry-apps-script.gs) 내용 **전체**를 붙여 넣은 뒤 저장(💾)해요.
4. 오른쪽 위 **배포 → 배포 관리**를 눌러요.
5. 지금 배포를 고르고 연필(✏️ 수정)을 눌러요 → **버전: 새 버전** → **배포**.
   - ⚠️ **"새 배포"를 누르면 주소가 바뀌어요.** 그러면 앱의 `INQUIRY_URL`도 새 주소로 바꿔야 해요.
   - 처음 바꿀 때 Google이 권한을 다시 물을 수 있어요. 본인 계정으로 **허용**해 주세요.
6. 아래 "잘 되는지 확인하기"를 해요.

## 처음 연결하는 경우

### 1. 스프레드시트 만들기

1. https://sheets.google.com 에서 **빈 스프레드시트**를 만들고 이름을 `한끼예산 문의`로 정해요.
2. 이 스프레드시트는 **공유하지 않아요.** 문의에는 연락처가 들어 있을 수 있어서, 보여 줄 팀원에게만 따로 공유해요.

### 2. 받는 코드 붙이기

1. 스프레드시트 위쪽 메뉴에서 **확장 프로그램 → Apps Script**를 열어요.
2. 기본으로 들어 있는 코드를 모두 지우고 [inquiry-apps-script.gs](inquiry-apps-script.gs) 내용 전체를 붙여 넣은 뒤 저장(💾)해요.

### 3. 웹 앱으로 배포하기

1. Apps Script 오른쪽 위 **배포 → 새 배포**를 눌러요.
2. 톱니바퀴(⚙) → **웹 앱**을 골라요.
3. 설정은 이렇게 해요.
   - **다음 사용자로 실행**: `나`
   - **액세스 권한이 있는 사용자**: `모든 사용자`
4. **배포**를 눌러요. 처음에는 Google이 권한을 물어요. 본인 계정으로 **허용**해 주세요.
   (이 코드는 **이 스프레드시트에만** 글을 쓰고, 다른 것은 읽거나 바꾸지 않아요.)
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해요.

### 4. 앱에 연결하기

`src/lib/inquiry.ts`의 `INQUIRY_URL`에 위에서 복사한 주소를 넣어요.

```ts
export const INQUIRY_URL = 'https://script.google.com/macros/s/.../exec';
```

주소가 들어가면 앱에 제보 버튼이 나타나요. 주소가 비어 있으면 버튼이 나오지 않아요.

## 잘 되는지 확인하기

1. 앱의 주변 식당에서 식당 카드를 펼치고 **메뉴 정보 수정 제보**를 하나 보내요.
2. 스프레드시트 아래쪽에 `메뉴 정보 수정` 시트가 생기고 한 줄이 들어오는지 봐요(몇 초 걸려요). 안 보이면 새로고침해요.
3. **식당 미등록 제보**도 하나 보내서 `식당 미등록 제보` 시트를 확인해요.
4. 시험으로 보낸 줄은 지워요.

## 엑셀로 보기

- **바로 보기**: Google Drive(drive.google.com, 휴대폰은 Google Sheets 앱)에서 스프레드시트를 열면 엑셀처럼 보이고, 정렬·필터도 돼요. 새 제보는 열어 둔 채로도 저절로 들어와요.
- **엑셀 파일로 받기**: 스프레드시트에서 **파일 → 다운로드 → Microsoft Excel(.xlsx)**. 모든 시트가 한 엑셀 파일에 탭으로 들어가요.

## 알아 두세요

- **웹 앱 주소는 공개돼요.** 이 주소로는 글을 **보낼 수만** 있고 읽을 수는 없어요. 다만 누구나 글을 보낼 수 있어서 스팸이 올 수 있어요. 앱에서 30초에 1번, 하루 5번으로 막고 함정 칸으로도 걸러요. 그래도 스팸이 많아지면 "새 배포"로 주소를 바꾸고 앱의 `INQUIRY_URL`도 바꿔요.
- **앱이 "보냈어요"라고 해도 실제로 시트에 들어갔는지는 앱이 알 수 없어요.** 브라우저가 Apps Script의 답을 읽을 수 없어서예요. 그래서 코드를 바꾼 뒤에는 꼭 "잘 되는지 확인하기"를 해요.
- **코드를 고치면 배포 관리에서 "새 버전"으로 다시 배포해야** 앱이 바뀐 코드를 써요. 저장만 해서는 바뀌지 않아요.
- 받는 코드를 바꾸기 전에 온 제보는 `문의` 시트에 종류 `기타`로 들어가 있어요. 내용 맨 앞의 `[메뉴 정보 수정 · 가격이 달라요 · 식당 이름]` 같은 머리말로 알아볼 수 있어요.
- **시트 이름은 바꾸지 마세요.** 바꾸면 코드가 그 시트를 못 찾아서 원래 이름으로 새 시트를 또 만들어요.
- 칸 순서를 바꾸면 새 줄이 엉뚱한 칸에 들어가요. 칸을 더 쓰고 싶으면 **오른쪽 끝에** 추가해요.
- Apps Script의 무료 사용량(하루 수천 건)이면 학교 앱에는 충분해요.
- 연락처에는 개인정보가 들어 있을 수 있어요. 시트는 필요한 사람에게만 공유하고, 처리가 끝난 문의는 정기적으로 지워 주세요.
